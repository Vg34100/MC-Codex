# Codex

Build quests on Minecraft advancements.

Codex brings a larger, resizable advancement view and in-game authoring tools to vanilla Minecraft, datapacks and modded advancement trees. Keep their native objectives and add optional story, item deliveries, claimable rewards, repeatable contracts and party progression.

## Included when you install

- Six enhanced vanilla advancements with field-note descriptions and optional journal text.
- The Camp Chronicle: a separate twelve-quest sample with story choices, deliveries, repeatable tasks, party contracts and treasure rewards.
- In-game advancement, reward, dialogue, branch, treasure-list and crafting/cooking recipe editors.
- Optional quest tracking, delivery receipts and configurable visual feedback.

The examples work without extra content mods, and pack makers can disable them. They do not change vanilla recipes or install a larger campaign. Sagittary/Sleep Cycle examples activate only when those optional mods are installed separately.

## For pack makers

Edit existing advancements or create new trees. Choose items and tags visually, retain complex definitions through advanced JSON, and keep authored content in an editable datapack. The recipe editor supports shaped/shapeless crafting and four native cooking types. Custom machine serializers use advanced JSON where compatible.

Use Edit Mode with operator permissions. Other players see the quests and share the server's definitions. Party sharing of ordinary vanilla advancements is intentional.

## Before downloading

Current development targets: Minecraft26.1.2, Fabric and NeoForge. Follow each release's actual dependency metadata. This page is a preparation draft; it is not evidence that a public release has been uploaded or that additional Minecraft versions are supported.

Editing content affects the installation's shared authoring pack. Read the included-example and recipe-editor guides before moving it into an existing pack. The framework is still being tested; report reproducible issues with loader/version, relevant logs, and your advancement/quest definitions.
